## Why This Project Was Created
Conducting online exams is vulnerable to academic dishonesty. This project was built to conduct strictly monitored exams automatically while giving educators a powerful Admin Dashboard to manage questions, subjects, and analytics across different college years (FYBCA, SYBCA, TYBCA) without relying on manual configuration files.

## Actual Use Cases & Capabilities
1. **Secure Environment**: Forces browser into fullscreen, monitors webcam, and catches tab switching/screenshots.
2. **Admin Dashboard**: A secure, mobile-friendly portal for educators to create/edit subjects, build question banks, and instantly view analytics, pass rates, and class leaderboards.
3. **Automated LMS**: The frontend dynamically loads the exact questions mapped to the student's selected class and subject from the cloud.

## How to Use It
1. **Admin**: Log in to `https://proctor-test-mcq.web.app/admin.html`. Use the mobile-friendly sidebar to add/edit your subjects, and populate the question bank.
2. **Student**: Provide the main web link to students. They select their class, subject, enter their name, and take the proctored test.
3. **Review**: The dashboard instantly updates with student scores, cheating violations, and leaderboard rankings.
